# shipknot.github.io

ShipKnot's site and app privacy policies, served by GitHub Pages.

Plain HTML and CSS: no build step, no scripts, no cookies, no tracking. Paths are relative, so pages open straight from disk too.

- `index.html`: home page
- `zen-mode/privacy/`: Zen Mode privacy policy (linked from its Play listing)
- `assets/fonts/`: Albert Sans, under the SIL Open Font License (`OFL.txt`)
